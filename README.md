# PitchAtlas ⚽🗺️

PitchAtlas is a cinematic football analytics platform that transforms traditional match data into immersive terrain exploration.

Instead of static dashboards and generic charts, PitchAtlas visualizes football intelligence through:

- Terrain-style heatmaps
- Elevation momentum curves
- Spatial movement systems
- Interactive match journeys
- Tactical traversal visualizations

The project focuses heavily on:

- Modern SaaS-level UI/UX
- Immersive frontend engineering
- Advanced data visualization
- Cinematic motion systems
- Scalable React architecture

## 🚀 Getting Started

1. **Clone Repository**

   ```bash
   git clone https://github.com/Crazyhaller/pitch-atlas
   ```

2. **Navigate Into Project**

   ```bash
   cd pitch-atlas
   ```

3. **Install Dependencies**

   ```bash
   npm install
   ```

4. **Create Environment Variables**

   Create a `.env.local` file:

   ```
   NEXT_PUBLIC_FOOTBALL_DATA_API_KEY=your_api_key
   NEXT_PUBLIC_API_FOOTBALL_KEY=your_api_key
   NEXT_PUBLIC_UNSPLASH_ACCESS_KEY=your_api_key
   ```
